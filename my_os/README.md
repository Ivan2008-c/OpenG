# MY OS - Операционная система для x86 с поддержкой FAT32 и форматом APP

## Описание
Это простая операционная система для архитектуры x86, которая включает:
- **Загрузчик** (boot.asm) - загружает ядро с диска
- **Ядро** (kernel.c) - базовое ядро с выводом на экран
- **Program Manager** - меню управления программами
- **Формат .app** - собственный формат исполняемых файлов
- **Поддержка FAT32** - структура для работы с файловой системой

## Структура проекта
```
my_os/
├── src/
│   ├── boot.asm      # Загрузчик (512 байт, первый сектор)
│   ├── kernel.c      # Ядро ОС
│   └── linker.ld     # Скрипт компоновщика
├── include/
│   └── kernel.h      # Заголовочный файл
├── apps/
│   └── hello.c       # Пример программы в формате .app
├── build.sh          # Скрипт сборки
└── README.md         # Этот файл
```

## Требования для сборки
- NASM (ассемблер)
- GCC или i686-elf-gcc (компилятор C)
- QEMU (эмулятор для тестирования)
- Linux/Unix среда

### Установка зависимостей (Ubuntu/Debian):
```bash
sudo apt update
sudo apt install nasm gcc qemu-system-x86 make
```

## Сборка
```bash
chmod +x build.sh
./build.sh
```

## Запуск
```bash
qemu-system-i386 -drive format=raw,file=myos.img
```

## Формат .app
Приложения в формате .app имеют следующую структуру заголовка:

```c
struct app_header {
    uint32_t magic;       // 0x41505058 ("APPX")
    uint32_t entry_point; // Точка входа
    uint32_t code_size;   // Размер кода
    uint32_t data_size;   // Размер данных
    char name[32];        // Имя программы
};
```

### Создание своей программы:
1. Напишите код на C в папке `apps/`
2. Используйте функцию `app_main()` как точку входа
3. Скомпилируйте с флагами для создания .app файла

Пример программы (`apps/hello.c`):
```c
void app_main() {
    // Ваш код здесь
    // Используйте системные вызовы ядра
}
```

## Program Manager
Встроенный менеджер программ позволяет:
- Просматривать доступные .app приложения
- Запускать программы
- Управлять процессами

Команды Program Manager:
- `run <name>` - запустить программу
- `list` - показать список программ
- `exit` - выйти из менеджера

## Архитектура
- **Архитектура**: x86 (32-bit Protected Mode)
- **Загрузчик**: BIOS Real Mode -> Protected Mode
- **Файловая система**: FAT32 (структура готова к реализации)
- **Видеорежим**: VGA Text Mode (80x25)

## Расширение функциональности

### Добавление поддержки FAT32:
Реализуйте функции чтения FAT32 в `src/fat32.c`:
- Чтение BPB (BIOS Parameter Block)
- Работа с кластерами
- Поиск файлов по имени

### Добавление системных вызовов:
Определите API ядра в `kernel.h`:
```c
void syscall_print(const char* str);
int syscall_read_file(const char* name, void* buffer);
void syscall_exit(int code);
```
